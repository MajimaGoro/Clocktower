# 后续修改入口

此工程是从已发布页面重构出的可编辑 ES 模块工程。它保留了原作者的角色数据与界面素材，没有恢复原作者原始工程中的 `.vue` 模板、注释、提交历史和构建配置。

## 原版与开发版

原版位于 `_archive/outputs/minibotc-local`，原压缩包也保留在 `_archive/outputs/`。开发版默认使用 8770 端口，浏览器按端口隔离数据，因此不会自动显示旧版的存档。

如果要读取某个旧本地网址的已有存档，可以先停止占用该端口的旧服务，再用开发版的 `npm run dev -- --port=原端口` 启动，并使用原来的浏览器和相同主机名（例如 `127.0.0.1`）。保留的数据键和格式使现有存档仍可读取；使用前可先备份浏览器网站数据。

## 测试与构建

修改领域规则后运行 `npm test`，修改任何源码后运行 `npm run check`。需要交付静态网站时运行 `npm run build`，`dist` 中同时包含图片和源模块。用 `npm run serve` 预览构建结果。

`docs/module-map.json` 记录各导出函数所在文件。测试直接导入这些真实模块，不需要 Vue、浏览器或 npm 依赖。角色与剧本的黄金校验值用于发现意外数据损坏；如果有意更新原数据，需审核变化后再更新对应测试基线。

## 尚可继续改善的部分

运行库保留在 `src/vendor/uni-runtime.js`，目前作为冻结依赖使用。业务组件虽然已经拆开并可直接修改，部分渲染与局部计算仍保留了编译产物的写法。可在后续功能迭代时逐个组件改写为更简洁的手写渲染或 Vue 模板，并用现有测试与页面行为做对照。

本轮集中做结构重构，没有新增联机后端或多人同步能力。
